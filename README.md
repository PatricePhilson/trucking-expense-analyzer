#Trucking Expense Analyzer 🚛

## Overview
A Python web application that helps trucking businesses
track load revenue, operating expenses, and profitability.

## Features
- Record load revenue and mileage
- Track fuel, maintenance, insurance, and other expenses
- Calculate net profit and profit margin
- Calculate operating cost per mile
- Visualize expenses by category
- Export load and expense records to CSV

## Technology Stack
- Python
- Streamlit
- Pandas
- GitHub

## How to Run Locally
1. Install Python.
2. Install dependencies:
   pip install -r requirements.txt
3. Start the application:
   streamlit run streamlit_app.py
